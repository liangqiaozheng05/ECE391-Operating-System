# Attribution and distribution notes

## University of Illinois course framework

The source snapshot includes files carrying University of Illinois copyright
notices for 2024-2025. Many identify the University of Illinois/NCSA Open
Source License through the SPDX identifier `NCSA`. Existing notices and
identifiers have been retained. `LICENSES/NCSA.txt` provides the standard
reference text; the original source headers identify the applicable holders.

License reference: https://opensource.org/license/ncsa

## VirtIO definitions

`sys/dev/virtio.h` contains BSD-style notices for imported VirtIO definitions,
including IBM Corporation and Red Hat notices. The original license blocks
are retained in that file.

## xv6-derived build configuration

`usr/Makefile` identifies itself as based on the xv6-riscv Makefile. The upstream
xv6 license is reproduced in `LICENSES/xv6-MIT.txt` for attribution. This does
not imply that every file in this repository is xv6-derived.

Source: https://github.com/mit-pdos/xv6-riscv/blob/riscv/LICENSE

## Student contributions

This is a team course project. Original in-file contributor attribution and
the original team account list in the README have been retained. No new
repository-wide license is assigned to student contributions or to files
whose licensing scope is not established by their existing notices. A public
GitHub repository alone is not permission to reuse every included file.

## Omitted material

Precompiled Trek, Rogue, and Zork game executables, Zork game data, and the
course's precompiled `mkfs_ktfs` executable are not included. The source
snapshot does not establish their redistribution terms; game executables
also contain developer home-directory paths. Generated binaries, disk images,
personal documents, and local credentials are excluded from the import.

Academic rules and permission to publish coursework are separate from source
license notices. No claim of instructor or university endorsement is made.
